# แผนประจำวัน — รถเข้า-ออก (FM-GM-01-07) / เครื่องจักร (FM-GM-01-03)

หน้า `/daily-plan` · ใช้ได้กับบัญชี **ธุรการ (staff)** และ **admin** (บัญชีผู้ดูแลพื้นที่/ลงนามอย่างเดียวเข้าไม่ได้)

## ติดตั้ง
```
node scripts/migrate_daily_plan.js     # สร้างตาราง dplan_* (รันซ้ำได้ ไม่ลบข้อมูล)
```
ไม่ต้องติดตั้ง package เพิ่ม · พิมพ์ฟอร์มใช้ปุ่ม "พิมพ์ฟอร์ม" ของเบราว์เซอร์ (A4 แนวนอน) ไม่ใช้ Chrome ฝั่ง server

## ตาราง
| ตาราง | เก็บอะไร |
|---|---|
| `dplan_resources` | รายชื่อรถ/เครื่องจักรของแต่ละโครงการ (แถวในแบบฟอร์ม) — เอาออก = ปิดใช้ ไม่ลบ |
| `dplan_plans` | แผน 1 ใบ = โครงการ × วัน × ฟอร์ม · เวลาที่ส่ง · ผลตรวจความครบถ้วน ณ ตอนส่ง · ไม่นับ KPI |
| `dplan_items` | รายการในแผน (รถ/เครื่อง × ช่วงเวลา × งาน × จุดกอง/ผู้ขอใช้) · `added_after` = เพิ่มหลังส่ง |

## การใช้งาน
1. แท็บ **ตั้งค่ารายชื่อ**: เลือกฟอร์ม + โครงการ → "ใช้รายชื่อตั้งต้นจากแบบฟอร์ม" → แก้ให้ตรงโครงการ → บันทึก
2. แท็บ **กรอกแผน**: เลือกวันที่ (ค่าเริ่มต้น = วันทำงานถัดไป) → เพิ่มแถว หรือ "คัดลอกจากแผนก่อน" → บันทึกร่าง → **ส่งแผน**
   - เครื่องจักร: 1 ใบ = ช่วง OT 17:00 น.– ของ "วันที่ช่วง OT" (ค่าเริ่มต้น = วันทำงานก่อนหน้า) + 07:00–17:00 ของวันที่ของแผน
   - เครื่องจักร: เลือก **ประเภทงาน** ต่อแถว (เทคอนกรีต / งานเหล็ก / งานไม้แบบ / งานผนังบ่อ-เสา / ยกของ / อื่น ๆ) → ใบพิมพ์ 01-03 ไฮไลต์สีตามประเภทงาน + ตารางบอกสีท้ายใบ · ลิฟท์ = เหลือง และรถโฟล์คลิฟท์ = เขียว ทั้งกลุ่ม (ไม่ต้องเลือก) · ไม่เลือก = เหลืองอ่อน
     (ต้องรัน `node scripts/migrate_daily_plan.js` อีกครั้งเพื่อเพิ่มคอลัมน์ work_type)
3. **พิมพ์ฟอร์ม** → ส่วน "ตรวจสอบความสมบูรณ์ของแผน" ในใบพิมพ์เว้นว่างทั้งหมด ให้ PE/PM ติ๊กและลงนามเอง
4. ธุรการสแกน/ถ่ายรูปใบที่ PE/PM เซ็นแล้ว → เปิดแผนวันนั้น → ส่วน **📎 ใบที่ PE/PM ตรวจ + ลงนามแล้ว**
   แนบไฟล์ (PDF / JPG / PNG ≤ 15 MB · รูปถูกย่อเหลือด้านยาว 2000px ก่อนส่ง) + เลือกผลตามที่ PE/PM ติ๊ก (สมบูรณ์ / ไม่สมบูรณ์ + ช่องที่ขาด)
   + ชื่อ/ตำแหน่ง PE/PM + วันที่ลงนาม → **ส่งใบเซ็น** · ส่งซ้ำ = แทนที่ไฟล์เดิม · admin ลบใบเซ็นได้
   ไฟล์เก็บที่ `storage/dplan-signed/<โครงการ>/` (นอก public) เปิดผ่าน `/api/dplan-signed/<id>` (ต้อง login) · รวมอยู่ในคลังเอกสาร /documents ด้วย
   (ต้องรัน `node scripts/migrate_daily_plan.js` อีกครั้งเพื่อเพิ่มคอลัมน์ signed_*)
5. แท็บ **KPI**: ดูรายเดือน/รายโครงการ + แผนที่รอใบเซ็น + แผนที่ไม่ครบ + ข้อมูลที่ขาดบ่อย

## KPI
**KPI = (จำนวนแผนที่ข้อมูลครบถ้วน ÷ จำนวนแผนทั้งหมดที่จัดทำ) × 100** — แยก 01-07 กับ 01-03
- "จัดทำ" = กดส่งแผนแล้ว **และส่งใบที่ PE/PM เซ็นแล้ว** · ยังไม่ส่งใบเซ็น = **รอใบเซ็น** ยังไม่อยู่ในตัวหาร (แท็บ KPI มีรายการให้ตาม)
- ร่างไม่นับ · แผนที่ **ไม่นับ** (ผู้ขอแจ้งหลัง 16:00 / ผู้ขอไม่ให้ข้อมูล) ไม่อยู่ในตัวหาร
- **ไม่นับ ยึดตามที่ PE/PM ติ๊กในใบเซ็น** — ธุรการเลือก "ไม่นับ + เหตุผล" ตอนส่งใบเซ็น · ปุ่ม "ไม่นับใน KPI" ในหน้าแผนเหลือเฉพาะ admin (แก้ทีหลัง)
  เก็บผู้ตั้ง/เวลาใน `excluded_by` / `excluded_at` (รัน `node scripts/migrate_daily_plan.js` อีกครั้ง) · ลบใบเซ็น = ล้าง "ไม่นับ" ด้วย
- ใบพิมพ์ใช้ฟอนต์ไทยจากระบบ (`fonts/tahoma.ttf` ผ่าน `/fonts/`) ไม่พึ่ง Google Fonts
- **ครบถ้วน / ไม่ครบ ยึดตามที่ PE/PM ติ๊กในใบเซ็น** (ธุรการกรอกผลตอนส่งใบเซ็น)
- ระบบยังตรวจช่องว่างตอนกดส่งครั้งแรก (ช่องที่ขาดเป็นสีแดง) เป็นตัวช่วยให้ธุรการเห็นก่อนพิมพ์ — ไม่อยู่ในสูตร KPI
- ช่องที่ระบบตรวจ — รถ (01-07): ทุกแถวต้องมี ทะเบียนรถ · ประเภทรถ · จุดกอง/จุดลงของ · เวลา
- เครื่องจักร (01-03): ทุกแถวต้องมี เครื่องจักร · ช่วงเวลา · งานที่ทำ · ผู้ขอใช้ (กลุ่มที่มีคำว่า "ลิฟท์" ไม่บังคับผู้ขอใช้ ตามแบบฟอร์ม)
- เวลาที่ส่งเทียบกำหนด 16:00 น. ของวันทำงานก่อนวันแผน (เครื่องจักร = วันที่ช่วง OT) แสดงประกอบ ไม่อยู่ในสูตร
  วันทำงาน = จันทร์–เสาร์ ไม่รวมวันหยุดในตาราง `transport_holidays` ของระบบขนส่ง

## สิทธิ์
- ธุรการ: กรอก/ส่ง/แก้ไข แผนทุกโครงการ · ตั้งรายชื่อ · ติ๊กไม่นับ · ลบได้เฉพาะร่าง
- admin: เหมือนธุรการ + ลบแผนที่ส่งแล้วได้
