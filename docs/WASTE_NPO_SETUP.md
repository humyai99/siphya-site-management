# ติดตั้งระบบติดตามขยะ + รายงาน NPO

หน้า `/waste` คือหน้าเดียวกับที่หน้างานใช้บน Google Apps Script (ฟอร์มบันทึก + Dashboard)
หน้า `/npo` เป็นหน้าใหม่ให้ธุรการออกรายงาน NPO (แทนการกดเมนูในชีต `report_<โครงการ>`)

## ติดตั้ง (ทำครั้งเดียว ต่อจาก docs/CHECKLIST_SETUP.md)

```bash
npm install                    # เพิ่ม sharp (ย่อรูปตอนทำ PDF)
node scripts/migrate_waste.js  # รันซ้ำได้ ไม่ลบข้อมูลเดิม
```

ใช้ตาราง `waste_records` และ `projects` ที่มีอยู่ เพิ่ม:
- `truck_types` อัตรารถ (6 ล้อเล็ก 3 คิว 550 / 6 ล้อใหญ่ 6 คิว 1,100 / 10 ล้อ 13.5 คิว 2,500) แก้ราคาในตารางนี้ได้เลย
- `npo_reports` หัวรายงาน NPO
- `waste_records.npo_id` เที่ยวไหนอยู่ NPO ไหน (แทนตัวนับเดิม), `waste_records.created_at`

## กติกา NPO

- แยกตาม **โครงการ + ประเภทรถ**
- ดึงเที่ยวที่ยังไม่เคยออก NPO เก่าสุดก่อน (วันที่ → เวลาเข้า) จำนวนตามที่ใส่ (ค่าตั้งต้น 50)
- เลข NPO พิมพ์เอง ห้ามซ้ำกับใบที่ยังใช้อยู่ · ช่วงวันที่คำนวณเอง (เดือนไทย ปี พ.ศ.)
- ลำดับเที่ยวนับต่อเนื่องตามโครงการ + ประเภทรถ
- ออก NPO + ทำ PDF อยู่ใน transaction เดียว ถ้า PDF พัง ไม่มีอะไรถูกบันทึก
- ยกเลิก NPO (ต้องใส่เหตุผล) → เที่ยวกลับเป็น "ยังไม่ออก" ออกใหม่ได้ เลขเดิมใช้ซ้ำได้
- เที่ยวที่กรอกย้อนหลังจะไปอยู่ใบถัดไป ไม่หาย

## รูปประกอบ (4 รูป บังคับทุกรูป)
1. รูปหน้ารถ 2. รูปขยะบนรถ 3. รูปก่อนคลุมผ้า — ครอปให้พอดีช่องในใบ NPO
4. **รูปบิล** (`waste_records.photo_bill_url`) — ย่ออย่างเดียว ไม่ครอป ให้อ่านเลขที่บิลได้ · **ไม่ขึ้นในใบ NPO** ดูได้จากแท็บแก้ไข/ลบรายการ (🧾 ดูรูปบิล)
- รายการเก่าที่ไม่มีรูปบิล: แก้ไขเมื่อไหร่ต้องแนบรูปบิลด้วย

## กันรถทะเบียนเดียวกันเวลาทับกัน
- ตอนบันทึก / แก้ไข / กู้คืน: ถ้ารถทะเบียนเดียวกัน (เทียบแบบตัดช่องว่าง/ขีด) วันเดียวกัน มีช่วงเวลาเข้า–ออกทับกับรายการอื่น
  (ทุกโครงการ) **ไม่ให้บันทึก** และบอกรายการที่ชน (โครงการ / โซน / เวลา / บิล / ผู้บันทึก) — เวลาต่อกันพอดีไม่นับว่าทับ
- เวลารถออกต้องหลังเวลาเข้า
- แท็บ **⚠️ รถซ้ำเวลา** (เห็นเฉพาะ admin) แสดงคู่ที่ทับกันซึ่งบันทึกไว้ก่อนมีการตรวจ พร้อมชื่อผู้บันทึก บัญชีที่ login ตอนกรอก และเวลาที่กรอก

## เตือนบิลน่าสงสัย (ต้องกดยืนยันก่อนบันทึก)
ตอนบันทึก / แก้ไข ถ้าเจอข้อใดข้อหนึ่ง ระบบเปิดกล่อง "ตรวจบิลก่อนบันทึก" โชว์รูปบิลที่บันทึกไว้แล้วเทียบกับบิลที่กำลังกรอก
1. **โครงการเดียวกัน วันเดียวกัน เวลาเข้า–ออกทับกัน แต่ทะเบียนต่างกัน** — กันเคสผู้รับเหมาเขียนทะเบียนผิด แล้วบิลเดียวกันถูกกรอก 2 ครั้ง
2. **เลขที่บิลเดียวกัน โครงการเดียวกัน แต่ทะเบียนต่างกัน** (ข้ามวันก็เตือน)
3. **ทะเบียนเดียวกัน คนละโครงการ** ออกจากที่หนึ่งแล้วเข้าอีกที่ห่างกันไม่ถึง 30 นาที (รถวิ่งไม่ทัน)

- กด "กลับไปแก้" = ไม่บันทึก · กด "ยืนยันว่าเป็นคนละเที่ยว" = บันทึก และเก็บชื่อบัญชีผู้ยืนยัน + เวลา + บิลที่ชน
  (`waste_records.warn_confirmed_by / warn_confirmed_at / warn_detail`)
- รถ 2 คันเข้าไซต์พร้อมกันได้จริง จึงแค่เตือน ไม่บล็อก — ต่างจาก "ทะเบียนเดียวกันเวลาทับกัน" ที่ยังบล็อกเหมือนเดิม
- แท็บ **⚠️ รถซ้ำเวลา / บิลน่าสงสัย** (admin) มีส่วน "🔎 บิลน่าสงสัย" ไว้ไล่ตรวจก่อนออก NPO / ทำ payment
  คอลัมน์ "ยืนยันว่าไม่ซ้ำ" ว่าง = บันทึกไว้ก่อนมีระบบเตือน
- ต้องรัน `node scripts/migrate_waste.js` อีกครั้งเพื่อเพิ่มคอลัมน์ (รันซ้ำได้)

## แก้ไข / ลบรายการ (แท็บ "✎ แก้ไข/ลบรายการ" ในหน้า /waste)
- ทุกคนที่ login แก้หรือลบได้ ค้นจากเลขบิล / ทะเบียน / ผู้บันทึก (แสดง 200 รายการล่าสุด)
- ตอนแก้ตรวจกฎเดิมทั้งหมด (ช่องบังคับ, สัดส่วน 100%, ประเภทรถ, บิล+ทะเบียนไม่ซ้ำ) ค่าใช้จ่าย/ปริมาณคิดใหม่ตามประเภทรถ
- รูปที่ไม่ได้ถ่ายใหม่ใช้รูปเดิม
- **เที่ยวที่ออกใบ NPO แล้วแก้/ลบไม่ได้** ต้องยกเลิกใบ NPO ก่อน (PDF ที่ออกไปแล้วจะได้ตรงกับข้อมูล)
- เก็บว่าใครแก้ล่าสุด (`updated_by`, `updated_at`) และค่าเดิมก่อนแก้/ลบทุกครั้งในตาราง `waste_record_history`
- **กู้คืนรายการที่ลบ**: ในแท็บเดียวกัน เลือก "แสดง: รายการที่ลบแล้ว" แล้วกด ↩ กู้คืน — ข้อมูล รูป และ id เดิมกลับมาครบ (ถ้ามีบิล+ทะเบียนเดียวกันอยู่แล้วจะไม่ให้กู้ซ้ำ)

## ประเภทรถและราคา (admin)
- หน้า /npo มีกล่อง "ประเภทรถและราคา" แสดงเฉพาะ admin: แก้คิว/ราคาต่อเที่ยว, ลำดับแสดง, เปิด/ปิด, เพิ่มประเภทใหม่
- ตัวเลือกประเภทรถในหน้าบันทึก (/waste) ดึงจากตาราง `truck_types` พร้อมป้ายคิว/ราคา
- ราคาใหม่มีผลกับเที่ยวที่บันทึกหลังจากนั้น (ราคาเก็บในแต่ละเที่ยวตอนบันทึก) เที่ยวเดิม/ใบ NPO เดิมไม่เปลี่ยน
- ลบประเภทไม่ได้ ให้ "ปิด" แทน (ประเภทที่ปิดแต่ยังมีเที่ยวค้างยังออก NPO ได้)

## ช่องลงนามท้ายใบ NPO
- ท้ายหน้าสุดท้าย (ใต้แถวรวม) มีช่อง "รับวางบิล" และ "อนุมัติ" พร้อมเส้นลงนาม
- ชื่อในวงเล็บพิมพ์ตอนออกใบ (หน้า /npo) ระบบจำชื่อครั้งล่าสุดของแต่ละโครงการไว้ เว้นว่าง = เส้นจุดให้เขียนมือ
- เก็บใน `npo_reports.receiver_name` / `approver_name`

## PDF

A4 แนวนอน หน้าละ 3 เที่ยว รูปเต็มกรอบ 69 × 52 มม. (วัดจาก PDF ตัวอย่างของระบบเดิม)
รูปถูกย่อเป็น 800 × 600 ก่อนใส่ (50 เที่ยว ≈ 7 MB แทน ~30 MB) ความคมตอนพิมพ์เท่าเดิม
ไฟล์อยู่ที่ `public/uploads/npo/<รหัสโครงการ>/`

## ข้อมูลเดิม

ระบบขยะยังไม่ได้ใช้งานจริงบน Google Sheet จึงเริ่มจากตารางว่างได้เลย ไม่ต้องย้ายข้อมูล

## ทดสอบแล้ว (PostgreSQL 16 + Node 22) ผ่าน 32/32

บันทึก + รูป 3 รูป, อัตรารถถูก, กันบันทึกซ้ำ, สัดส่วนไม่ครบ 100 / ไม่มีรูป / ประเภทรถแปลก ถูกปฏิเสธ,
Dashboard ใช้หัวคอลัมน์เดิม, นับค้างแยกตามประเภทรถ, ตัวอย่างไม่บันทึก, ออก NPO + PDF,
เลขซ้ำถูกปฏิเสธ, เที่ยวย้อนหลังไปใบถัดไป, ยกเลิกแล้วเที่ยวกลับมา + ลบไฟล์, ออกใหม่ด้วยเลขเดิมได้,
ไฟล์ PDF หายสร้างใหม่ได้ และถ้า Chrome ที่ใช้ทำ PDF ปิดไป ระบบเปิดใหม่เอง
